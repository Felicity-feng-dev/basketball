# 小篮球教练教案工具

单文件、离线可用的少儿篮球训练教案生成器。面向 U8 / U10 / U12 三个年龄段，内置 36 个训练环节，覆盖体能与脚步、运球、传球、投篮、防守、团队配合等维度。

## 打开方式

直接双击 `index.html` 用浏览器打开即可，不需安装、不需联网、没有构建步骤。`file://` 下可正常排课、打印和使用计时器；Service Worker 仅在 `http(s)://` 下注册，部署到静态站点后可离线打开。

## 两步式排课（#175）

1. 首屏只有「填需求」表单：年龄段、主题、时长、人数、常用场地、难度、器材。桌面端单列居中，最宽 760px；手机 375px 正常使用。此时教案区完全不出现。
2. 点「生成整节课教案」后，表单收成顶部一行摘要（年龄段 · 主题 · 时长 · 人数 · 难度），教案出现并自动回到页面顶部。
3. 点摘要右侧「修改需求」可回到表单，所有已选值保留，改完再生成即可。

教案按「热身 → 技术 → 组合/对抗 → 体能 → 放松」自动配平到所选分钟数，逐环节给出动作要点、口令、常见错误与纠正、进阶/退阶、可量化评估和家长话术，并附半场 SVG 示意图。

## 班级档案与自动轮换（#176）

- 顶部班级栏可「新建班级 / 选班级 / 存回该班」；班级档案含班名、年龄段、人数、难度、器材、常用场地六项，写入浏览器 `localStorage`，刷新页面或重开 PWA 都还在。
- 选中班级会自动填入六项档案；改完字段点「存回该班」更新档案，不点则只影响本次排课。
- 每次生成教案自动记一条上课记录：班级、日期、主题、环节 id 列表。点「记录 / 备份」可看该班最近 5 次练了什么，并可单条删除（删后不再计入轮换）。
- 同一个班下次生成时，优先避开该班最近 2 次用过的环节。可替换环节不够时允许复用，但教案顶部会明确显示「复用（可选环节不足）」，复用环节标「复用」。
- 「记录 / 备份」里可导出全部班级与记录的 JSON，也可导入覆盖；导入前先确认，格式不对会拒绝，不会写坏原数据。数据只在本机浏览器，不联网。

## 上课运行态（#177）

- 点「开始上课」进入整屏运行态：顶部显示「01/06」和剩余总时长，中间是大字倒计时，下面是当前环节的名称、时长、动作要点、口令和评估；操作按钮固定在底部，不随内容滚走。
- 倒计时可开始 / 暂停 / 继续 / 重置；「上一环节 / 跳过 / 下一环节 / 结束」按环节切换，到点用 WebAudio 提示并自动进入下一环节。
- 运行中请求 Screen Wake Lock，支持的浏览器不熄屏；不支持或被拒绝时静默跳过，不弹窗、不报错。
- 点「退出」只暂停并回到教案，保留当前环节、剩余秒数和页面滚动位置；再点「继续上课」接着倒数。「结束」才清空本节计时。
- 375px 竖屏与横屏均不横向滚动；竖屏按钮高 48px，横屏 44px。

## 家长课报（#178）

- 教案页点「生成课报」，得到一段可直接粘到微信的纯文本：日期 / 对象 / 主题 / 时长 / 本次环节数 + 每个环节一句家长听得懂的话 + 下次预告。
- 全文不超过 200 字，只改写每个环节已有的「家长一句话」，不新增方法论或数字；课报内不含链接，也不出现「AI / 工具 / 网站」这类词。已用 3 个年龄段 × 7 个主题 × 6 种时长 × 4 种人数 × 3 档难度共 1,512 种组合实测，最长 200 字。
- 点「复制」写入剪贴板；复制失败时自动全选只读文本框，按 Ctrl+C 或长按复制，不会只剩一条报错。

## 场地条件过滤（#179）

- 需求区新增「场地条件」：室内 / 室外、有篮筐 / 无篮筐、场地不限 / 半场 / 全场，以及「空间不足半场」勾选项。
- 选「无篮筐」后，投篮、上篮、罚球、篮板、快攻终结、半场三对三等需要篮筐的环节不再进入教案；选「半场」或勾「空间不足半场」后，全场折返、长传快攻、全场紧逼等长距离环节不再进入教案。两项可叠加，默认「不限 / 有篮筐 / 不勾」保持原有排课结果。
- 教案里始终有一个可展开的「为什么没选某些环节（N）」，逐条写明「无篮筐：投篮练习已跳过」这类原因，每条一句。
- 条件过滤后若主课池为空（或整池被轮换排除），自动给出无筐 / 小空间安全清单，教案顶部标「替代方案（已标注）」，每个替代环节带「替代」标记，绝不生成空课。
- 室内 / 室外只改变教案上的条件说明，不虚构没有依据的环节剔除。

## 孩子档案与四项评分（#180）

- 班级栏点「孩子评分」：一个班可建多个孩子，每个孩子有姓名和备注，可改名、改备注、删除；删除该孩子会连同 TA 的评分一起删，不影响同班其他孩子。
- 选中孩子可看四项最近分数（运球 / 传球 / 投篮 / 防守），每项按日期记 1–5 分；同一孩子可记多次，评分按日期新到旧排列。
- 详情卡显示四项最新分数和变化方向：`↑` 上升、`↓` 下降、`→` 持平，首次记录显示「— 首次」；下方列出最近 3 次表现备注。
- 孩子和评分都嵌在所属班级里，随现有 JSON 备份一起导出 / 导入，顶层仍是 `version:1`。旧备份没有 `children` 字段（或为 `null`）时按空班级处理，不报错，原班级与上课记录照常保留。

## 课时计数与「已上」（#181）

- 班级栏可设「总课时 M」（1–200，默认 10），旁边直接显示「第 N 节 / 共 M 节 / 剩 K 节」；K≤2 时标黄，并写「只剩 K 节，请提前续课」。
- 生成教案只落一条「待上」历史，N 不变；点班级栏的「标记已上」把最近一条「待上」转成「已上」，没有待上时补一条「补记」。上课运行态里按「结束」或倒计时走完也会把本节记为「已上」，同一条历史重复结束不会重复计数。
- N 只由该班历史里 `taught` 的条数算出，不另存计数器；生成、删除、导入后都按历史重算。手动修正 N 时按「按修正值对齐历史」处理：调高就补「补记」已上历史，调低就把多出的已上记录标成「已冲正」，历史一条不删，页面会明确提示这是对齐规则。
- 旧备份没有 `totalLessons` / `taught` 字段也能导入：M 默认 10，旧记录按「已上」处理，不会丢历史或抛错。

## 打印

「打印教案」只输出教案正文，表单、班级栏、上课记录弹窗、摘要、顶部按钮、运行态和动作库/规则页不会打印，避免浪费纸张。

## 规则核验（2026-11-22）

页面「年龄与器材规则」逐条标注核验状态：

- ① 原文已核：中国篮协《小篮球规则》官方 PDF 第 2/3/4 条（U8/U10/U12 的球号、篮高、场地、罚球线）。
- ② 仅栏目存在：中国小篮球官方频道只有导航与赛事新闻。

②③ 行均注明「以官方最新规则为准」；页面底部写明当天实测失败的具体情况，不把未核到的内容写成已核。

## 安全卡（#182）

- 独立的「安全卡」页签：课前检查清单（场地 / 鞋 / 热身）、扭伤 · 擦伤 · 中暑第一处理、紧急电话、家长知情提示。
- 只写通用安全常识，不写冰敷几分钟、体温多少度这类没把握的数字；每条旁注「非医疗建议，严重立即就医」。
- 页内「打印安全卡」只输出这一页 A4，教案、表单、课报和导航都不会进入打印；从教案页普通打印也不会带上安全卡。

## 新建班级（#185）

- 点顶部「新建班级」立即弹框问班名；确认后立刻建班，出现在班级下拉并自动选中，页面弹出「已新建：班名」提示。
- 空名 / 纯空格不建班，弹框内提示；重名直接拒绝并提示换名（不自动加后缀）。
- 取消、Esc、点遮罩都能退出，且不改动当前选中的班；「存回该班」仍只改当前班档案，不掺新建逻辑。
